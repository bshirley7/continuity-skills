# Default Project Goal Dispatch

When the portfolio supervisor returns a due `dispatch` action, start a separate task in that repository, record the scheduler run with the selected due goal ID, run `project doctor`, and apply its installed `$continuity-local` behavior with `$continuity-dispatch`. Dispatch at most one goal per project when it is approved, due, dependency-satisfied, unlocked, and preflight-compliant. During execution, send heartbeats, apply `$continuity-test` after implementation and before PR handoff, then apply `$continuity-merge` for merge-safety assessment. End successful overnight delivery at `review-ready`; never record business completion or merge without next-business-day human review evidence. Start different projects concurrently within the portfolio cap. Never infer approval, bypass failed gates, execute held work, auto-merge, force-push, or move private state outside its project. Record task IDs, configuration hash, test report, merge assessment, and local dispatch outcomes.
