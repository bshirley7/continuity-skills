# Default Project Goal Dispatch

At the configured dispatch time, use `continuity --json portfolio due --root <workspace-root>` for every developer-configured workspace root. For each returned project whose manifest has `execution_enabled: true`, start a separate task in that repository, run `project doctor`, and apply its installed `$continuity-local` behavior with `$continuity-dispatch`. Dispatch at most one goal per project when it is approved, due, dependency-satisfied, unlocked, and preflight-compliant. During the execution loop, apply `$continuity-test` after implementation and before PR handoff, then apply `$continuity-merge` for merge-safety assessment. Start different projects concurrently. Never infer approval, bypass failed gates, execute held work, auto-merge, force-push, or move private state outside its project. Record task IDs, configuration hash, test report, merge assessment, and local dispatch outcomes.
