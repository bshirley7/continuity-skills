# Morning Continuity Report

At the configured report time, use `continuity --json portfolio queue --root <workspace-root>` for every developer-configured workspace root. Produce a report for every discovered project regardless of completion state. Each project task must run `project doctor` and apply its installed `$continuity-local` behavior with `$continuity-report`. Include notes retained as knowledge, memory and roadmap health, releases, milestones, sprints, risks, imported shared packets, plans awaiting review, approved queues, running or validating goals, latest `$continuity-test` status, missing test evidence, security findings, latest `$continuity-merge` assessment, completed or partial work, blockers, PR and evidence status, compliance stages, configuration health, and feedback needed. Aggregate only sanitized summaries; never centralize raw captures or private ledgers. Never claim completion without recorded alignment, validation, security, merge-safety, documentation, memory-impact, and roadmap-impact evidence.
