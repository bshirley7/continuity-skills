# Morning Continuity Report

When the portfolio supervisor returns a due `report` action, start a project task, record the scheduler run, run `project doctor`, and apply `$continuity-local` with `$continuity-report`. Generate `report morning` and `report project` even when the project has no goals. Lead with exactly three decision surfaces: decisions needed, completed overnight, and blocked or at risk. For every decision, include the goal or note ID, recommendation, evidence or PR, and the available human disposition. Then include prepared plans, queues, memory and roadmap health, tests, security, merge assessment, compliance, and configuration health. Treat `review-ready` as awaiting human disposition, not business completion. Aggregate only sanitized summaries; never centralize raw captures or private ledgers.
