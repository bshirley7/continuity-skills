# Morning Continuity Report

When the portfolio supervisor returns a due `report` action, start a project task with its exact one-time claim token and idempotency key, record the scheduler run, run `project doctor` and `workflow status`, and apply `$continuity-local` with `$continuity-report`. Generate `note patterns`, `report morning`, and `report project` even when the project has no goals. Lead with exactly three decision surfaces: decisions needed, completed overnight, and blocked or at risk. For every decision, include the goal or note ID, recommendation, current evidence or PR, and structured `allowed_dispositions` containing currently valid command templates. List `blocked_dispositions` with their live evidence failures separately. Honor deferred review dates and matching pattern dispositions so accepted, dismissed, or not-yet-due decisions do not recur. Then include note counts by exact lifecycle stage, stage-entry dates, planning dispositions, later-work anchors, unconfirmed relationship suggestions, per-goal workflow status, queues, patterns, prepared plans, memory and roadmap health, active runs, tests, security, merge, compliance, evidence, and configuration health. Treat patterns and similarity as planning input rather than authorization, and `review-ready` as awaiting human disposition rather than business completion. Aggregate only sanitized summaries; never centralize raw captures or private ledgers.
