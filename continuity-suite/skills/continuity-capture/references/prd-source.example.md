# Synthetic Review Workspace PRD

## Problem

Reviewers lose time when risk context is separated from the item being approved.

## Objective

Reduce review time while preserving the current screen's scanability.

## Requirements

### REQ-1: Risk context

Show the risk summary beside the approval details.

Acceptance: reviewers can see the summary without leaving the approval view, and keyboard behavior remains unchanged.

### REQ-2: Export

Export remains outside the first release and should be reconsidered after launch.

## Open question

Should external reviewers see internal confidence labels?
