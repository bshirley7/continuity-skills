# Composition, grid, and spatial rhythm

## Generalized principles

- Define a compositional contract before arranging components: establish content bounds, columns, gutters, outer margins, primary reading axes, alignment lines, module spans, vertical intervals, and the rules by which regions may nest, overlap, alternate, or break the grid.
- Use span, position, scale, whitespace, and grouping to express semantic priority and dependency; modules that support comparison should share relevant alignment and dimensions, while modules with different roles should not be forced into visual equality.
- Treat spacing as relational syntax: use repeatable intervals to bind labels to values, controls to affected content, items to groups, groups to sections, and sections to changes in task or argument; do not use generous whitespace without a structural or narrative purpose.
- Make asymmetry and grid breaks deliberate exceptions: identify the emphasis, transition, sequence, or identity they create; retain enough shared edges, reading order, contrast, and return to rhythm that the exception strengthens composition without obscuring task or meaning.
- Compose narrative surfaces as a sequence of claim, explanation, demonstration, proof, and action when those roles apply; vary placement and scale for pacing while preserving a recognizable internal grid and clear transitions between arguments.
- Specify how the composition transforms rather than merely shrinks: preserve semantic grouping, dominant content, comparison relationships, reading order, and action proximity as columns collapse, modules serialize, imagery crops, and whitespace changes across widths.
- Evaluate the full page or task sequence at realistic content density: test long and short content, empty and error states, repeated modules, mixed media, localization, zoom, narrow and wide viewports, and the cumulative rhythm created by adjacent sections rather than approving isolated components.

## Variation levers

- Use a stricter repeated grid when comparison, scanning, or operational speed dominates.
- Use larger span contrast and more pronounced pacing when narrative, editorial emphasis, or discovery dominates.
- Increase negative space between changes in argument or task while keeping related controls and evidence close.
- Allow asymmetry around one dominant anchor rather than distributing exceptions across every module.
- Use denser intervals within expert work regions and broader intervals between independent regions.
- Serialize modules on narrow layouts in semantic order rather than preserving desktop coordinates.

## Tensions and tradeoffs

- A rigid grid improves scanability while flattening content roles and expressive hierarchy.
- Asymmetry creates emphasis and identity while weakening predictability and responsive transformation.
- Generous whitespace clarifies grouping while reducing visible context and operational throughput.
- Dense repeated modules support comparison while creating monotony and cumulative visual load.
- Alternating layouts improve pacing while producing zigzag reading and inconsistent action placement.
- Overlap and layering create depth while increasing occlusion, contrast, localization, and implementation risk.

## Failure modes

- Components are aligned locally but the page has no coherent reading axis or section rhythm.
- Every module occupies the same span and visual weight regardless of role.
- Whitespace is used decoratively without communicating grouping or transition.
- An asymmetric composition has no stable anchor, reading order, or responsive fallback.
- Alternating sections move headings, actions, and evidence unpredictably.
- A desktop grid collapses by source order rather than semantic dependency.
- Isolated components look polished while realistic page density creates crowding or dead zones.
- Content length, localization, zoom, error states, and absent media break alignment or grouping.

## Anti-patterns

- Twelve-column grid as a default answer.
- Equal cards for unequal meaning.
- Whitespace as status.
- Random asymmetry.
- Alternating zigzag by habit.
- Overlap without fallback.
- Desktop coordinates serialized blindly.
- Component-only composition review.
- Perfect placeholder rhythm.

## Acceptance and review questions

- Are content bounds, columns, gutters, margins, reading axes, module spans, intervals, nesting, overlap, and exception rules explicit?
- Do span, position, scale, whitespace, and grouping reflect semantic priority and comparison relationships?
- Does spacing consistently distinguish item, group, section, and task or argument transitions?
- Does every grid break or asymmetric move have a stated purpose, stable anchor, reading order, and responsive fallback?
- Do narrative sections preserve claim, explanation, demonstration, proof, and action relationships where applicable?
- Does responsive transformation preserve grouping, dominant content, comparison, reading order, and action proximity?
- Has the complete page or task been tested with realistic density, variable content, localization, zoom, failure states, and missing media?
- Can the composition be described as a reusable grammar rather than a screenshot-specific arrangement?
