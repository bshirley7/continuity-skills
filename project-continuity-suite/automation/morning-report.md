# Morning Project Continuity Report

At the configured report time, use `continuity --json portfolio queue --root <workspace-root>` for every developer-configured workspace root. Produce a report for every discovered project regardless of completion state. Each project task must read its own installed skills and local state. Include notes retained as knowledge, memory-health changes, plans awaiting review, approved queues, running or validating goals, completed or partial work, blockers, PR and evidence status, compliance stages, and feedback needed. Aggregate only sanitized summaries; never centralize raw captures or private ledgers. Never claim completion without recorded alignment, validation, security, merge-safety, documentation, and memory-impact evidence.
