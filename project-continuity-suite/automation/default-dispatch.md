# Default Project Goal Dispatch

At the configured dispatch time, use `continuity --json portfolio due --root <workspace-root>` for every developer-configured workspace root. For each returned project whose manifest has `execution_enabled: true`, start a separate task in that repository and invoke its installed CLI. Dispatch at most one goal per project when it is approved, due, dependency-satisfied, unlocked, and preflight-compliant. Start different projects concurrently. Never infer approval, bypass failed gates, execute held work, or move private state outside its project. Record task IDs and local dispatch outcomes.
