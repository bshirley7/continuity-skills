# Nightly Project Continuity Review

Use `project-continuity-suite/registry/projects.json` and the installed continuity skills. At 8:00 PM America/Chicago:

1. Triage new captures conservatively; notes never authorize work.
2. Update private knowledge ledgers and revisit eligible deferred items.
3. Rebuild and audit trusted project-memory indexes.
4. Produce project updates even when no action is warranted.
5. Create decision-complete proposed goals only from eligible candidates.
6. Leave every new goal awaiting feedback; do not approve or dispatch it.
7. Record compliance evidence for capture-triage, memory retrieval, and plan review.
